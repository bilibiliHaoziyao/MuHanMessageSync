# 慕寒消息云同步

![Version](https://img.shields.io/badge/version-1.1.0-pink) ![License](https://img.shields.io/badge/license-MIT-green)

一款 Android 通知云同步工具，**软件内整合服务端与接收端**：

- **服务端模式**：通过系统「通知使用权」监听本机**所有通知**，实时通过**电子邮箱（SMTP）**转发出去。
- **接收端模式**：通过 **IMAP 实时收信**（优先 IDLE 长连接，自动退化为轮询），将邮件还原为系统通知。
- **应用图标随通知传输**：服务端抓取源应用图标并以 Base64 随邮件发送，接收端跨设备也能还原带图标的通知。
- **本地同步历史**：首页以时间线展示服务端转发与接收端收到的通知（带应用图标、收发方向、来源设备），支持搜索、按收发方向筛选、点击复制内容、删除单条、清空，顶部显示今日 / 累计统计。
- **通知点击直达应用**：接收端点击同步通知时，若本机已安装来源应用则直接打开该应用，否则回到历史页。
- **多设备支持**：服务端可配置多个收件人邮箱；多个接收端可共用同一邮箱，基于 Message-ID 本地去重，互不干扰。
- **邮箱服务商快速预设**：内置 QQ邮箱 / 163邮箱 / Gmail / Outlook 预设，一键填入 SMTP / IMAP 服务器与端口。
- **丰富的自定义选项**：转发过滤（全部 / 白名单 / 黑名单）、跳过无文字或系统应用通知、合并重复内容、轮询间隔、通知优先级、震动 / 提示音、历史保留条数与天数、深色模式、应用图标显示等。
- **沉浸式界面**：适配沉浸式状态栏与全面屏手势小白条（edge-to-edge）。
- **首次进入引导**：引导开启「通知使用权」与「后台保活」（忽略电池优化），确保同步稳定运行。
- **开机自启**：前台常驻服务，重启后自动恢复。

## 工作原理

```
┌──────────────┐   通知监听    ┌──────────────┐   SMTP 邮件   ┌──────────────┐   IMAP 收信   ┌──────────────┐
│  手机 A 通知  │ ───────────> │  服务端模式   │ ───────────> │   邮箱服务器  │ ───────────> │  接收端模式   │ ──> 手机 B 通知
└──────────────┘   (含图标)   └──────────────┘  (含图标)     └──────────────┘              └──────────────┘
```

## 使用方法

1. **首次进入**：按引导开启「通知使用权」与「后台保活」（建议同时在系统设置中允许自启动）。
2. **配置服务器**：进入「设置 → 邮箱服务器设置」，选择服务端 / 接收端模式，点击邮箱服务商预设一键填入服务器，填写账号、授权码与收件人，点击「启动服务」。
3. **服务端设备**：选择「服务端（转发通知）」，使用 QQ / 163 / Gmail / Outlook 预设，填写账号与授权码、收件人邮箱，启动服务。
4. **接收端设备**：选择「接收端（还原通知）」，使用同一服务商预设，填写账号与授权码，启动服务。
5. **查看历史**：返回首页即可看到同步历史（带应用图标）；可搜索关键字、按「仅发送 / 仅接收」筛选，点击条目复制内容，长按删除单条；顶部显示今日 / 累计条数。「设置 → 同步选项」可调整转发过滤、轮询、通知与历史等。
6. 多台接收端设备可共用同一收件邮箱，实现多设备同时接收。
