# 慕寒消息云同步

![Version](https://img.shields.io/badge/version-0.2.0--beta-pink) ![License](https://img.shields.io/badge/license-MIT-green)

一款 Android 通知云同步工具，**软件内整合服务端与接收端**：

- **服务端模式**：通过系统「通知使用权」监听本机**所有通知**，实时通过**电子邮箱（SMTP）**转发出去。
- **接收端模式**：通过 **IMAP 实时收信**（优先 IDLE 长连接，自动退化为轮询），将邮件还原为系统通知。
- **多设备支持**：服务端可配置多个收件人邮箱；多个接收端可共用同一邮箱，基于 Message-ID 本地去重，互不干扰。
- **邮箱服务商快速预设**：内置 QQ邮箱 / 163邮箱 / Gmail / Outlook 预设，一键填入 SMTP / IMAP 服务器与端口。
- **首次进入引导**：引导开启「通知使用权」与「后台保活」（忽略电池优化），确保同步稳定运行。
- **开机自启**：前台常驻服务，重启后自动恢复。

## 工作原理

```
┌──────────────┐   通知监听    ┌──────────────┐   SMTP 邮件   ┌──────────────┐   IMAP 收信   ┌──────────────┐
│  手机 A 通知  │ ───────────> │  服务端模式   │ ───────────> │   邮箱服务器  │ ───────────> │  接收端模式   │ ──> 手机 B 通知
└──────────────┘              └──────────────┘              └──────────────┘              └──────────────┘
```

## 使用方法

1. **首次进入**：按引导开启「通知使用权」与「后台保活」（建议同时在系统设置中允许自启动）。
2. **服务端设备**：选择「服务端（转发通知）」，点击邮箱服务商预设一键填入服务器（如 QQ 邮箱 `smtp.qq.com:465`），填写账号与授权码、收件人邮箱，点击「启动服务」。
3. **接收端设备**：选择「接收端（还原通知）」，点击同一服务商预设（如 `imap.qq.com:993`），填写账号与授权码，点击「启动服务」。
4. 多台接收端设备可共用同一收件邮箱，实现多设备同时接收。
