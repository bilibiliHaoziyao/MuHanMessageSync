# 慕寒消息云同步

![Version](https://img.shields.io/badge/version-0.1.0--beta-pink) ![License](https://img.shields.io/badge/license-MIT-green)

一款 Android 通知云同步工具，**软件内整合服务端与接收端**：

- **服务端模式**：通过系统「通知使用权」监听本机**所有通知**，实时通过**电子邮箱（SMTP）**转发出去。
- **接收端模式**：通过 **IMAP 实时收信**（优先 IDLE 长连接，自动退化为轮询），将邮件还原为系统通知。
- **多设备支持**：服务端可配置多个收件人邮箱；多个接收端可共用同一邮箱，基于 Message-ID 本地去重，互不干扰。
- **开机自启**：前台常驻服务，重启后自动恢复。

## 工作原理

```
┌──────────────┐   通知监听    ┌──────────────┐   SMTP 邮件   ┌──────────────┐   IMAP 收信   ┌──────────────┐
│  手机 A 通知  │ ───────────> │  服务端模式   │ ───────────> │   邮箱服务器  │ ───────────> │  接收端模式   │ ──> 手机 B 通知
└──────────────┘              └──────────────┘              └──────────────┘              └──────────────┘
```

## 使用方法

1. **服务端设备**：选择「服务端（转发通知）」，填写 SMTP 设置（如 QQ 邮箱 `smtp.qq.com:465`，使用授权码），填写收件人邮箱，点击「启动服务」并授予「通知使用权」。
2. **接收端设备**：选择「接收端（还原通知）」，填写 IMAP 设置（如 `imap.qq.com:993`，使用授权码），点击「启动服务」。
3. 多台接收端设备可共用同一收件邮箱，实现多设备同时接收。
